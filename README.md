# hungportfolio

Personal developer portfolio for Huynh Anh Hung / DarqPL.

Built with Next.js, Tailwind CSS, MDX, and shadcn/ui. The site is data-driven so projects, stack, experience, education, and notes can be updated from `src/data` without rewriting page components.

## Development

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` starts the local development server.
- `npm run build` creates a production build.
- `npm run lint` runs ESLint.
- `npm run typecheck` runs TypeScript without emitting files.

## Configuration

Set `NEXT_PUBLIC_SITE_URL` in the deployment environment when the final domain is ready.
